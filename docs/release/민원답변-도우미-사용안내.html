  3. Codex 항목의 ChatGPT로 로그인을 누릅니다. PowerShell 로그인 창이 열립니다.
  4. 로그인 창이 안내하는 공식 브라우저 화면에서 본인 ChatGPT 계정으로 인증합니다. 로그인을 마칠 때까지 민원답변 도우미를 닫지 마세요.
  5. 완료 후 로그인 창 안내에 따라 Enter로 창을 닫고, 앱에서 연결 상태 다시 확인을 누릅니다. Codex가 연결됨으로 표시되는지 확인합니다.
이 앱은 Codex 로그인을 별도 폴더에 보관합니다. 기존 Codex에서 로그인했더라도 이 앱에서는 최초 1회 별도로 로그인해야 합니다. Codex 연결에는 OpenAI API Key를 입력하지 않습니다.
Codex CLI가 없거나 버전이 다른 경우

공식 Codex CLI 설치 안내를 확인하세요. 앱이 표시하는 설치 명령은 아래와 같습니다. npm 방식으로 설치하려면 PC에 Node.js·npm이 별도로 준비되어 있어야 합니다. EXE에 포함된 런타임은 앱 실행용입니다.

npm install -g @openai/codex@0.160.0

이 명령은 PC의 전역 Codex CLI 버전을 변경할 수 있습니다. 다른 작업에서 Codex를 사용 중이면 기존 환경에 미치는 영향을 확인한 뒤 설치하세요. 앱은 CLI를 자동 설치하거나 업데이트하지 않습니다.

로그인 창이 열리지 않는 경우

작업 표시줄에 PowerShell 창이 있는지 확인하세요. 창이 없다면 앱의 로그인 안내에 표시된 실제 경로의 codex-login.ps1을 사용합니다. 아래 명령의 <설치 폴더>는 실제 폴더로 바꾸세요.

powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<설치 폴더>\codex-login.ps1"

기본 설치 폴더는 %LOCALAPPDATA%\Programs\minwon-answer\0.5.1입니다. 같은 버전을 다시 빌드한 경우 폴더명에 빌드 식별자가 붙을 수 있으므로 화면에 표시된 경로를 우선하세요.

Gemini 연결 사용자 API Key

  1. Google AI Studio의 API 키 페이지에서 본인 프로젝트의 Gemini API Key를 준비합니다. 프로젝트의 이용 권한·할당량·과금 조건도 확인하세요.
  2. 앱의 AI 연결 설정 → Google Gemini API에서 Gemini API Key 입력란에 키를 넣습니다.
  3. API 연결 확인을 누릅니다. 앱이 모델 목록을 조회하고 API 키 연결됨을 표시하는지 확인합니다.
  4. 단계별 제공사·모델에서 Gemini와 사용할 모델을 선택하고 설정 저장을 누릅니다.
키는 현재 서버 세션의 메모리에만 보관됩니다. 앱 종료·세션 만료·현재 세션 비우기 후에는 다시 입력해야 합니다. 연결 해제로 현재 세션의 키를 지울 수 있습니다. 작업 내보내기 파일에는 키가 포함되지 않습니다.

모델 목록 조회 성공과 실제 답변 생성 성공은 별개입니다. 실제 생성은 실행 단계에서 전송 내용을 확인하고 동의한 뒤 요청합니다. 키 관리 방법은 Google 공식 API 키 안내를 참조하세요.

06 · WRITE

연결한 뒤 단계별 AI를 선택하세요.

  1. AI 연결 설정 아래의 단계별 제공사·모델에서 초안·검토·재작성 각각에 사용할 제공사와 모델을 선택합니다.
  2. 설정 저장을 누릅니다. 연결만 완료하고 제공사를 바꾸지 않으면 데모가 선택된 단계는 계속 데모로 동작합니다.
  3. 가상 예시나 공개 비기밀 자료를 입력한 뒤 입력 저장을 누릅니다.
  4. 초안 생성·검토·재작성을 실행할 때마다 표시되는 전송 내용과 제공사를 확인하고 동의합니다. 동의한 단계의 내용이 선택한 외부 AI로 전송됩니다.
  5. 결과의 사실·근거·질문별 답변을 직접 확인합니다. 재작성하거나 답변을 수정하면 현재 버전을 다시 검토하고 담당자 점검을 저장한 뒤 확정합니다.

민원 입력 → 초안 생성 → 검토 → 재작성 → 현재 버전 재검토 → 담당자 확인

앱 화면은 내 PC에서 실행되지만, 실제 AI 생성을 선택하면 동의한 내용은 해당 제공사로 전송됩니다. 연결됨 표시는 인증·필요 기능 확인 결과이며 실제 생성 완료를 뜻하지 않습니다. 담당자 확정 후에도 기관 결재나 민원 발송은 별도로 처리해야 합니다.

내려받은 EXE의 SHA-256 확인

EXE와 같은 릴리스의 .sha256 파일을 내려받습니다. EXE가 있는 폴더에서 PowerShell을 열고 아래 명령으로 계산한 Hash를 파일의 값과 대조합니다.

Get-FileHash -Algorithm SHA256 -LiteralPath ".\minwon-answer-0.5.1-win-x64.exe"

해시가 같다는 것은 비교한 파일과 동일하다는 뜻입니다. 발행자 신원이나 기관의 실행 승인을 대신하지 않습니다.

앱의 화면 문구와 v0.5.1 소스의 연결 방식을 기준으로 작성했습니다. 이 안내서 작성 중 실제 계정 로그인이나 AI 생성 요청은 실행하지 않았습니다. 계정별 이용 조건과 제공사의 설치 절차는 공식 문서에서 확인하세요.
