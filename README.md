# 민원답변 도우미 · minwon-answer

교육행정 민원의 초안 생성 → 검토 → 재작성 → 담당자 확인을 지원하는 웹 앱입니다. 12개 분야와 8개 처리 유형, 질문별 대응 점검, 의견 선택, 버전 비교를 제공합니다.

## 실행 구조

- Vercel은 HTML·JavaScript·CSS 화면 파일만 제공합니다.
- 사용자 PC에서 실행한 Node 프로그램이 민원·답변·세션·AI 요청을 처리합니다.
- Codex·Claude는 PC의 공식 CLI 로그인, Gemini는 세션용 사용자 API Key를 사용합니다.
- AI 로그인 토큰·API Key·민원 본문을 Vercel 서버에 업로드하지 않습니다. 웹 화면에는 작업 데이터가 브라우저 메모리로 전달됩니다.
- 웹 주소는 로컬 화면에서 명시적으로 승인해야 합니다. 연결 코드·세션은 메모리 보관이며 단계별 AI 전송 동의와 구분합니다.

## 처음 사용하기

Node.js 22 이상이 필요합니다. 추가 npm 패키지 설치는 없습니다.

```powershell
git clone https://github.com/newskool4d-sketch/minwon-answer-web.git
Set-Location -LiteralPath '.\minwon-answer-web'
node server/index.mjs
```

1. 로컬 화면 `http://127.0.0.1:8793`을 엽니다.
2. Codex 최초 연결은 `codex-login.ps1`을 실행하고 공식 ChatGPT 로그인을 완료합니다. 앱 전용 Codex 홈을 사용하며 기존 인증정보를 복사하지 않습니다. Claude는 공식 Claude Code의 본인 구독 로그인을 사용합니다.
3. Vercel 웹 화면에서 표시하는 웹 origin을 복사합니다.
4. 로컬 화면의 **웹 연결 관리**에서 해당 origin과 연결 권한을 확인하고 일회용 코드를 발급합니다.
5. Vercel 웹 화면에 연결 코드를 입력합니다. 브라우저가 이 기기/로컬 네트워크 접근 권한을 요청하면 대상 웹 주소를 확인한 뒤 직접 허용합니다.
6. 가상 예시로 시작하여 AI 연결 설정과 단계별 전송 미리보기를 확인합니다.

로컬 화면만 사용해도 됩니다. 외부 웹 연결은 기본 꺼짐이며 로컬 프로그램은 `127.0.0.1`에만 바인딩합니다. 다른 PC에서 이용하려면 그 PC에서도 프로그램과 본인 로그인이 필요합니다.

## 데이터와 연결 경계

- 일회용 연결 코드: 정확한 HTTPS origin에 한정, 5분 만료·사용 후 폐기.
- 웹 세션: 쿠키 없이 메모리 bearer·CSRF·Origin을 함께 확인. 기본 30분 유휴 만료.
- 로컬 세션·다른 웹 세션의 민원과 Gemini Key를 승계하지 않습니다.
- 로컬 **웹 연결 해제** 또는 웹 **연결 해제**로 권한을 회수할 수 있습니다.
- 서버 종료·세션 만료 시 작업이 사라집니다. 필요한 결과는 미리 내려받으세요.
- 실제 민원·비공개·민감 자료의 외부 AI 전송은 MVP에서 계속 차단합니다. 자동 마스킹·동의만으로 실자료 운영을 허용하지 않습니다.
- 재작성 후에는 현재 버전을 다시 검토해야 하며 기관 결재·실제 민원 발송을 자동 처리하지 않습니다.

## Codex 로그인

공식 네이티브 Codex CLI 0.160.0의 검증된 기능을 사용합니다. 다른 버전은 호환·격리 검증 전 `setup` 상태로 제한합니다. 별도 패키지를 자동 설치하거나 모델을 임의로 대체하지 않습니다.

앱 전용 홈은 `%LOCALAPPDATA%\minwon-answer\codex-home`입니다. 해당 홈의 개인 지침 파일을 발견하면 생성을 차단합니다. 셸·패치·검색·REPL·이미지 기능과 개인 설정을 제한하고 실행별 임시 자료를 정리합니다. 이는 OS 전체 읽기 접근 차단을 뜻하지 않습니다.

기존 로컬/오픈소스 CLI 인증과 상용 호스팅용 SIWC는 구분합니다. 이 앱은 개인 PC에서 실행하며 Vercel이 로그인·모델 호출을 대행하지 않습니다. [공식 인증 경계](https://learn.chatgpt.com/docs/app-server#auth-endpoints).

## 개발·검증·배포

```powershell
node --test
node scripts/build-web.mjs
```

Vercel에는 `dist`의 화면 파일 3개만 배포합니다. `vercel.json`에 빌드 명령·출력 경로·보안 헤더가 지정되어 있습니다. 인증 파일·로컬 작업 기록·실호출 보고서는 Git에 포함하지 않습니다.

`scripts/smoke-codex.mjs --live-fictional`은 실제 외부 전송과 구독 사용량을 발생시키므로 사용자의 명시적인 가상 실호출 요청이 있을 때만 실행합니다.

연결 API와 검증 경계는 [배포 안내](docs/DEPLOYMENT.md)를 참고하세요.
